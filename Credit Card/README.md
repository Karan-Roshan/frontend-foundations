# Credit Card UI Design
A modern and minimal **Credit Card UI Design** built using **HTML and CSS**.  
This project focuses on creating a sleek, realistic credit card layout with clean typography, balanced spacing, and an elegant gradient background.

## Features
- **Modern Design:** A premium gradient background with soft shadows for a 3D effect.  
- **Clean Layout:** Well-structured HTML with semantic tags and organized sections.  
- **Typography:** Uses Google Font “Poppins” for a smooth and professional look.  
- **Responsive Structure:** Scales nicely on different screen sizes.  
- **Simple & Lightweight:** Built purely with HTML and CSS — no frameworks required.

## Design Overview
The credit card is designed to reflect a realistic yet minimal user interface with the following elements:
- **Header:** Contains the logo and chip icon.
- **Card Details Section:** Displays the card number, cardholder name, and validity date.
- **Gradient Background:** Enhances visual depth and professionalism.
- **Shadow and Border Radius:** Add realism to the overall card look.


## Layout Details
- **Card Dimensions:** 450px (width) × 250px (height)
- **Border Radius:** 25px for smooth rounded edges
- **Box Shadow:** 0 10px 25px rgba(0, 0, 0, 0.3) for depth
- **Primary Gradient:** linear-gradient(135deg, #0f2027, #203a43, #2c5364)
- **Font:** Poppins, weights 300–600
