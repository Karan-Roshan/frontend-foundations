# Magazine Project
A responsive **Magazine-style Webpage** built using **HTML5 and CSS3**.  
This page showcases a modern article layout with a hero section, author info, social media links, project history, images, and beautifully styled text with responsive design.

# Features
- Hero section with **title & subtitle**  
- Author info with **publish date & external link**  
- **Social media icons** (Facebook, Twitter, Instagram, LinkedIn, YouTube)  
- Drop-cap **first letter styling** for article opening  
- Styled **quotes & blockquotes**  
- “Brief History” section with timeline-style list  
- Images with **grid-based layout**  
- Fully **responsive design** with multiple breakpoints  
- Clean typography using **Google Fonts (Anton, Baskervville, Raleway)**  


# Tech Stack
- **HTML5** (semantic structure)  
- **CSS3**  
  - CSS Grid Layout  
  - Media Queries (responsive design)  
  - Google Fonts  
  - Font Awesome Icons

# Responsive Design
- ≤ 720px → Image wrapper stacks into one column
- ≤ 600px → Text-with-images becomes single column
- ≤ 550px → Font sizes adjust for readability
- ≤ 420px → Hero title scales down
