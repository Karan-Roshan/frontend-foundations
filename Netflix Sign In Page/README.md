# Netflix Sign-In Page
A clean and responsive **Netflix Sign-In Page Clone** built using **HTML & CSS**.  
This project focuses on modern UI design, floating labels, responsive layout, and Netflix-style aesthetics.


## Project Preview
A visually accurate clone of Netflix’s login page with:
- Floating input labels
- Dark UI theme
- Responsive design
- Netflix-style buttons and layout
