# Ping – Coming Soon Landing Page
A clean, responsive, and minimal **Coming Soon** webpage built with pure **HTML and CSS**.  
This project follows best front-end practices and is optimized for both desktop and mobile screens.


## Overview
The **Ping Coming Soon** page allows users to subscribe and get notified about the product launch.  
It features a centered layout, simple typography, a responsive design, and social media integration.

## Features
- Fully responsive (mobile, tablet & desktop)
- Modern, clean layout using **Flexbox**
- Accessible design (ARIA labels, alt text, proper contrast)
- Styled using only **CSS** (no JavaScript)
- Font Awesome icons integration
- Simple email subscription form

### Typography
- **Font Family:** [Poppins](https://fonts.google.com/specimen/Poppins)
- **Weights Used:** 300, 400, 500, 600
- **Base Font Size:** 15px (responsive)
- **Heading Size:** 35px → 28px → 24px (responsive)
- **Button Text:** 15px
- **Footer Text:** 10–15px

### Components
- Rounded **input field** with border & placeholder
- Blue **pill-shaped button** with hover effect
- **Responsive form layout** (horizontal → vertical)
- **Social icons** with hover animation

- **HTML5** – Semantic and accessible markup  
- **CSS3** – Responsive design using Flexbox and media queries
