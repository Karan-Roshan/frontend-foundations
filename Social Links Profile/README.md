# Social Links Profile Card 
It’s a clean and responsive social profile card built using **HTML** and **CSS**.  
The project demonstrates my understanding of semantic HTML, Flexbox layout, and responsive design principles.

## Overview
### The Goal
Users should be able to:
- View the social links profile in both mobile and desktop layouts.  
- See hover states for all interactive elements.  
- Access external links in new browser tabs.  
- Experience a clean, accessible, and responsive design.


## Built With
- **HTML5** – Semantic structure  
- **CSS3** – Flexbox layout and hover effects  
- **Responsive Design** – Works across mobile and desktop    
- **Modern Styling** – Dark theme with accent colors
